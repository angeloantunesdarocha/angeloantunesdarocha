## Projetos

### FaturApp — SaaS de controle de lucro real

Aplicação web em produção que calcula o lucro líquido real de motoristas e entregadores de aplicativo, descontando combustível, taxas e custos operacionais.

- **Demonstração:** [fatur-app.vercel.app/comece](https://fatur-app.vercel.app/comece)
- **Repositório:** [angeloantunesdarocha/FaturApp](https://github.com/angeloantunesdarocha/FaturApp)
- **Stack:** Next.js 15, React 19, TypeScript, Supabase (PostgreSQL), Tailwind CSS, Vercel
- **Destaques:** motor financeiro isolado com testes de regressão, três modos de cálculo de consumo de combustível, autenticação com Google OAuth, exportação em PDF e Excel

### ProntoDoc — Gerador de currículos online

Ferramenta web de criação de currículos para o mercado brasileiro, com exportação em PDF, simulação de entrevista, integração de pagamento e estratégia de SEO própria.

- **Repositório:** [angeloantunesdarocha/prontodoc-curriculo](https://github.com/angeloantunesdarocha/prontodoc-curriculo)
- **Stack:** Next.js, React, TypeScript

### Studio Tarcia Madureira — Site institucional para cliente

Site responsivo com catálogo de serviços, galeria, localização via Google Maps e agendamento pelo WhatsApp.

- **Repositório:** [angeloantunesdarocha/studio-tarcia-madureira](https://github.com/angeloantunesdarocha/studio-tarcia-madureira)
